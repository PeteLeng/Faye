# Faye

An Emacs-native LLM client with independent, persistent sessions.

Faye is designed for any buffer — files, read-only buffers, even the
minibuffer. A selected region can be the complete prompt. Sessions own
conversation records independently of the buffers they came from.

**Status:** pre-MVP scaffold. The design record is
[docs/spec.md](docs/spec.md); the implementation plan is
[docs/roadmap.md](docs/roadmap.md).

Provider target: a ChatGPT (Plus/Pro) subscription via OpenAI OAuth and the
Codex Responses endpoint. See the spec for the agreed scope.

The working local core provides records, a live session registry, buffer
attachment, file associations, request-option defaults, and user-record
forks. `require 'faye` loads it. Provider transport, interactive views, and
SQLite persistence follow the roadmap; M1 request assembly is next.

## Layout

| File            | Responsibility                                             |
|-----------------|------------------------------------------------------------|
| `faye.el`       | Entry commands, options menu, request orchestration.        |
| `faye-session.el` | Session records, registry, attachment, forks; SQLite planned. |
| `faye-openai.el`  | OAuth, Codex request construction, Curl/SSE transport.     |
| `faye-view.el`  | Org session views and the draft area.                       |
| `faye-context.el` | `@include` and prompt macro expansion.                    |
| `faye-output.el`  | View/append/replace/echo output actions.                  |
| `test/`         | ERT test suite.                                             |

## Development

- Emacs 29.1 or newer; no external package dependencies. The SQLite
  persistence milestone requires native support (`sqlite-available-p`).
- `make test` — run the ERT suite in batch mode.
- `make compile` — byte-compile every module, failing on warnings/errors.
- `make check` — compile and run the tests.
- `make clean` — remove generated bytecode.

## Naming

Faye is a working name. MELPA already hosts unrelated SageMath tooling, so
check for collisions before any public release.
